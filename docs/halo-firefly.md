# Halo + Firefly

Firefly keeps its Astro theme as the public blog, while Halo remains the only content management console.

## Local development

Start Halo first, then start Firefly:

```bash
cd /home/wsluser/workspace/github/CuteLeaf/Firefly
pnpm start:halo -- --host 127.0.0.1 --port 4321
```

The managed preview polls Halo content, categories, tags, and Firefly settings every five seconds. A change triggers a fresh sync and static rebuild; the previous build stays available if the rebuild fails. The `predev`, `precheck`, and `prebuild` hooks also run `pnpm sync:halo` automatically. The sync script reads published posts, categories, tags, covers, and post HTML from Halo and writes generated Markdown to `.content/posts/`.

For a one-off refresh:

```bash
pnpm sync:halo
pnpm build
```

If Halo is temporarily unavailable, the sync keeps the last successful generated content. A first build without a successful sync is intentionally empty instead of publishing Firefly's template posts. Set `HALO_REQUIRED=true` in CI or production builds when a missing Halo response must fail the build.

## Configuration

### Firefly 前端配置

在 Halo 控制台打开 `系统 -> 基本设置 -> Firefly 前端`，即可管理公开站点配置。Halo 不再作为公开主题使用，Firefly 是唯一对外展示的前端。

可管理的内容包括：

- 站点标题、副标题、地址、描述、关键词、语言、分页和页面开关
- 主题色、颜色模式、卡片样式和文章列表布局
- 导航栏样式和自定义链接
- 壁纸、首页横幅文字、打字机和轮播
- 侧栏布局、组件开关和公告
- 头像、昵称、个人简介
- QQ、邮箱、GitHub 等社交链接（图标名称使用 Iconify 格式）
- 导航栏/侧栏播放器、Meting 歌单或本地歌单、音量、循环方式和歌词

保存后，托管预览会在下一轮轮询中同步并重建 Firefly。单独执行静态构建时运行 `pnpm sync:halo && pnpm build`。Firefly 是 Astro 静态站点，设置会通过重新生成页面发布，而不是由页面运行时动态读取。Meting 认证字段不会通过公开接口返回。头像、壁纸和本地音乐附件会自动转换为 Halo 的绝对地址。

Use the public Halo origin, without `/console`:

```bash
PUBLIC_HALO_API_URL=https://halo.example.com
```

The default local value is `http://127.0.0.1:8090`. Halo's public storage paths remain absolute Halo URLs, so the Halo origin must stay reachable by readers for covers and attachments to load. Halo must also allow the Firefly origin through CORS for public comments.

Comments use Halo's public comment API. The selected service is configured in `src/config/commentConfig.ts` with `type: "halo"`; comments can then be moderated from Halo's console.

Search is generated by Pagefind during `pnpm build`, and homepage pagination is generated by Astro from the same synced content. A new Halo post therefore becomes public after the managed preview's next sync and Firefly build.
